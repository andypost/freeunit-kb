# FreeUnit 1.37.0 — in-flight release classification (checked 2026-09-17)

**Status:** unreleased; 152 commits on `master` since the `1.36.1` tag (29 Aug 2026).

## Classification: MINOR (1.37.0), confirmed against the tree

Andrey's call (2026-09-17): "Range и прочее скорее будут минором". The tree agrees —
the unreleased section carries two user-visible features and several operator-visible
breaking changes, so the release policy (patch = security/DoS fixes only; features /
API / breaking changes → minor) puts it at 1.37.0.

Entry tally in the unreleased section of `CHANGES` on `master`:
6 Security, 16 Change, 12 Bugfix, **2 Feature**.

Features:
- **byte-range requests for static files** — single-range `Range: bytes=…` →
  `206` + `Content-Range`, unsatisfiable → `416`, `Accept-Ranges: bytes` on a plain
  200, `If-Range` honoured (strong comparison), preconditions still evaluated first,
  multi-range deliberately answered with a full 200 (RFC 9110 permits). Served from a
  Range is not content-coded.
- **conditional requests for static files** — `If-None-Match` / `If-Modified-Since`
  → `304`; `If-Match` / `If-Unmodified-Since` → `412`; weak comparison, `*` matches.

Breaking / operator-visible Changes (why it cannot be a patch):
- `unitctl` no longer reads **JSON5** (and earlier in the same window: no **hjson**,
  no **YAML**), no longer re-serializes a configuration file (sends it as written),
  no longer reorders members, and offers **no HTTP/2** in the TLS handshake it makes.
- `unitctl` TLS behind a `tls` Cargo feature (default on); the **musl build no longer
  links a C TLS library** and refuses an `https://` control-socket address.
- A content-coded response now carries a **weak** entity-tag.
- Removals: GnuTLS/CyaSSL/PolarSSL backends, the fiber implementation, `nxt_mem_zone`,
  `nxt_queue.c`, the unused job cluster, the `nxt_dyld` wrapper.
- **njs 1.0.1** upgrade.

Security entries in the same section (announcement material — they are mixed into a
minor, so they need to be stated explicitly):
- `access_log` string format no longer writes what a variable expanded to unescaped —
  `"%0d%0a"` in a URL put a real CRLF (and a forged record) into the log; bytes are now
  escaped nginx-style (`\xHH`). A log parser expecting raw bytes must be updated.
- A port message queued because the peer's socket was not writable no longer borrows the
  descriptors it carries (a port closed before the queue drained could name a closed or
  recycled descriptor) (#388).
- Application processes no longer inherit `unitd`'s … (privileges/descriptors — read the
  entry text before quoting).
- Static-request and port-send descriptor leaks; `unitctl` dependency-pruning entry.

## Blocking issues for this release (re-checked 2026-09-28)

The `CHANGES` section header on `master` still reads
`Changes with FreeUnit 1.36.2    30 Aug 2026` while `version` says `1.36.1` and the
section now holds 2 Feature + 16 Change + 6 Security entries — it must be re-labelled
**1.37.0** with the actual release date, or the changelog contradicts the version and
the policy. (Still true at the 2026-09-28 tip `d4c8558f`.)

Static-request issues — state moved since 2026-09-17:
- **#355 CLOSED** (a range served as identity to a client that refused identity)
- **#390 CLOSED** (a file below min_length served as identity to a client that refused it)
- **#356 OPEN** (ETag cannot see a same-size rewrite within one second)
- **#391 OPEN** (HEAD carries no content-coding headers)

Unreleased Security work that landed after 1.36.1 and needs its changelog wording
(treated in `engineering/port-message-trust-model.md`): the router's port-message
sender gate, PR **#506** (merged 2026-09-27) plus three follow-up commits
(2026-09-27/28). It gates every type on the router main port through
`nxt_router_gate_handler()`, leaves `RPC` peer-binding, router-engine ports over the
shared-memory queue, `DETACHED`, non-credential platforms and the dispatcher-level ACL
open, and — per this repo's convention — a `*) Security:` entry has to name the
affected releases, because the missing check shipped long before this cycle. Issue
**#341** is still open with zero comments and no linked PR: annotate or close it when
the release ships.
