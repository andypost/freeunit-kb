# 🚀 FreeUnit 1.36.0

Released July 16, 2026. 307 files changed, +19,034 / −5,581 lines vs 1.35.5.

## 📡 OpenTelemetry — Complete Rewrite

- **OTel SDK upgrade:** Rust crates from 0.24 to 0.32. Exporter rewritten on a dedicated-thread batch span processor — no tokio runtime, blocking reqwest client.
- **gRPC returns:** `settings/telemetry/protocol` = `http` or `grpc`. OTLP/gRPC via tonic with minimal tokio runtime, plaintext h2c only (no TLS yet).
- **Traceparent:** upstream sampling decision propagated through `ParentBased(TraceIdRatioBased)` — W3C trace flags are now honoured.
- **mock OTLP collector:** `test/fake_otlp/` and `test_otel.py` — full test suite covering span export, propagation, sampling, config validation.
- **Config validation:** `batch_size` (1–65536) and `sampling_ratio` (0–1) now produce clear error messages.
- **Logging:** eprintln from the Rust layer replaced with C callback `nxt_otel_log_cb` — OTel errors flow through standard Unit logging infrastructure.

## 🛠 Bug Fixes

- **Go port-fd double-close:** getUnixConn() duplicated the fd via net.FileConn while a deferred Close() closed the original descriptor — race with libunit, intermittent EBADF. Fixed.
- **Cgroup.procs path bounds:** snprintf return value overwrote the length before bounds check — overflow on long paths. Now fails with ENAMETOOLONG.
- **Cgroup directory leak:** on pool allocation OOM, the created directory is now removed instead of leaking.
- **Proxy keepalive:** after a duplicate or invalid upstream Content-Length, downstream keepalive stays disabled — the client cannot reuse the connection past the re-framed response.
- **Static NUL/empty paths:** reject in templated share and chroot paths.
- **Controller conn tracking:** coherent connection tracking with full teardown on failure paths.
- **H1 buffer chain:** buf chain tail completion after Content-Length trim detaches it.

## 📦 Packaging & Infrastructure

- **Debian rebrand:** full package set renamed — `freeunit`, `freeunit-dev`, `freeunit-php8.x`, `freeunit-python3.x`, `freeunit-perl`, `freeunit-go`, `freeunit-wasm`, `freeunit-jscNN`. Binary: `/usr/sbin/freeunitd`, socket: `control.freeunit.sock`.
- **njs:** contrib upgraded to 1.0.0.
- **CI:** ASan+UBSan gate over lifecycle+runtime subsets, seccomp and clang-ast gates.
- **Docker:** regenerated Dockerfiles for 1.36.0.
