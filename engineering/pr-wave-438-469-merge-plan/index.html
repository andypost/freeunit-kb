Review-burden note

~22k lines across 31 PRs, none reviewed by a human yet. The real bottleneck is review bandwidth and merge order, not regressions: the code is defensive and additive, breaking changes are few and correct (new refusals instead of silent corruption), and the new build features are all opt-in (--hardening off, --h2 opt-in, --usdt opt-in) — a default build is unchanged.
