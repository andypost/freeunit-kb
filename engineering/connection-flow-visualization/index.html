Step-by-Step: One HTTP Request

Phase 1: Accept (router, ~50µs)

LISTENER (epoll fd)                        ROUTER
     │                                        │
     │  epoll_wait → EPOLLIN on listen fd     │
     │──────────────────────────────────────➤│
     │                                        │ nxt_conn_accept()
     │                                        │ → accept4(listen_fd, SOCK_NONBLOCK)
     │                                        │ → new conn_fd = 42
     │                                        │ → nxt_conn_t c = { .fd = 42,
     │                                        │     .read = nxt_h1p_conn_read }
     │                                        │
     │                                        │ nxt_event_engine_add(ev, conn_fd)
     │                                        │ → epoll_ctl(EPOLL_CTL_ADD, 42, EPOLLIN|EPOLLRDHUP)
     │                                        │
     │                                        │ c->state = NXT_CONN_ACCEPTED
     │                                        │ → ready_handler = nxt_h1p_request_header_read

Phase 2: Read & Parse Headers (router, ~200µs for typical request)

CLIENT                                    ROUTER (h1proto)
     │                                        │
     │  GET /index.php HTTP/1.1               │
     │  Host: example.com                     │
     │  Content-Length: 42                    │
     │──────────────────────────────────────➤│ epoll_wait → EPOLLIN on conn_fd=42
     │                                        │    ↓
     │                                        │ nxt_h1p_conn_read(c)
     │                                        │   → recv(42, c->read.buf, 4096) → 120 bytes
     │                                        │    ↓
     │                                        │ nxt_http_parse_request(buf, 120)
     │                                        │   → method = GET
     │                                        │   → target = /index.php
     │                                        │   → version = HTTP/1.1
     │                                        │   → headers parsed: 3 headers
     │                                        │    ↓
     │                                        │ nxt_h1p_request_header_ready(r)

Phase 3: Route Match (router, ~10µs)

     │                                        │
     │                                        │ nxt_http_route_find(r, "/index.php")
     │                                        │   → location match: "*.php"
     │                                        │   → app_name = "drupal"
     │                                        │   → action = proxy → app worker
     │                                        │    ↓
     │                                        │ r->app = drupal_app
     │                                        │ r->app->type = NXT_APP_PHP

Phase 4: Select Worker (router, ~5µs)

     │                                        │
     │                                        │ nxt_router_app_process_select(app)
     │                                        │   → round-robin over app->workers[]
     │                                        │   → selected: worker #3, pid = 12345
     │                                        │    ↓
     │                                        │ worker = &app->workers[3]
     │                                        │ port  = worker->app_port  (UDS socket pair)

Phase 5: IPC Send Request → Worker (router → worker, ~20µs small, ~200µs with mmap)

ROUTER                                    IPC                            WORKER
     │                                      │                                │
     │ nxt_router_app_process_request()     │                                │
     │   ↓                                  │                                │
     │ Build message header:                │                                │
     │   nxt_port_send_msg_t msg = {        │                                │
     │     .type = NXT_PORT_MSG_DATA,       │                                │
     │     .stream = request_id,            │                                │
     │     .pid = router_pid                │                                │
     │   }                                  │                                │
     │   ↓                                  │                                │
     │ Body ≤ 64KB?                         │                                │
     │   ┌─ YES ─ write(sock_fd, msg+body)──➤ UDS packet (single write)───➤│
     │   │                                  │  ↓                             │
     │   │                                  │  nxt_port_read_msg()           │
     │   │                                  │  → read(sock_fd) → msg+body   │
     │   │                                  │                                │
     │   └─ NO ─ nxt_port_mmap_write()      │                                │
     │             ↓                        │                                │
     │          mmap(NULL, body_size,        │                                │
     │               PROT_READ|PROT_WRITE,   │                                │
     │               MAP_SHARED,             │                                │
     │               mem_fd, offset)         │                                │
     │             ↓                        │                                │
     │          memcpy(shm, body)            │                                │
     │             ↓                        │                                │
     │          write(sock_fd,               │                                │
     │            msg + mmap_header)  ─────➤│  → mmap(same_fd, same_off)     │
     │          (tiny: ~64 bytes)            │    → worker reads from SHM     │
     │                                      │                                │
     │                                      │    nxt_unit_run()              │
     │                                      │    → dispatch to language      │
     │                                      │      ↓                         │

Phase 6: Worker Processing (PHP worker, ~50ms for Drupal, ~2ms for "hello world")

                                        WORKER (PHP SAPI)
                                             │
                                             │ nxt_php_setup() [one-time at boot]
                                             │   → tsrm_startup()
                                             │   → php_module_startup()
                                             │   → opcache.enable = 1
                                             │
                                             │ nxt_php_request_handler(r)
                                             │   ↓
                                             │ Build $_SERVER:
                                             │   REQUEST_METHOD = GET
                                             │   REQUEST_URI    = /index.php
                                             │   HTTP_HOST      = example.com
                                             │   CONTENT_LENGTH = 42
                                             │   ↓
                                             │ php_request_startup()
                                             │   ↓
                                             │ zend_execute_scripts(index.php)
                                             │   → autoloader
                                             │   → DrupalKernel::handle()
                                             │   → routing
                                             │   → controller
                                             │   → Response: 200 OK, HTML body
                                             │   ↓
                                             │ php_request_shutdown()
                                             │   → flush output
                                             │   → close session

Phase 7: IPC Send Response → Router (worker → router, ~20µs small)

WORKER                                    IPC                            ROUTER
     │                                      │                                │
     │ nxt_unit_response_send(r)            │                                │
     │   ↓                                  │                                │
     │ Write response through port:         │                                │
     │   write(sock_fd,                     │                                │
     │     msg(type=DATA, stream=req_id)    │                                │
     │     + status_line                    │                                │
     │     + headers                        │                                │
     │     + body)                   ──────➤│ read(sock_fd) ─────────────➤   │
     │                                      │  ↓                             │
     │                                      │ nxt_router_response_ready()    │
     │                                      │  → r = pending[req_id]         │
     │                                      │  → r->state = RESPONSE_READY   │

Phase 8: Write Response → Client (router, ~50µs)

                                             │
                                             │ nxt_h1p_response_send(r)
                                             │   ↓
                                             │ Build HTTP response:
                                             │   HTTP/1.1 200 OK
                                             │   Content-Type: text/html
                                             │   Content-Length: 12345
                                             │   Connection: keep-alive
                                             │    ↓
                                             │ nxt_conn_write(c, buf)
                                             │   → writev(conn_fd, iov, iovcnt)
                                             │     iov[0] = status_line
                                             │     iov[1] = headers
                                             │     iov[2] = body (mmap or socket)
                                             │
CLIENT                                       │
     │  HTTP/1.1 200 OK                      │
     │  Content-Type: text/html              │
     │  Content-Length: 12345               │
     │←──────────────────────────────────────│
     │  [HTML body: 12345 bytes]            │
     │←──────────────────────────────────────│

Memory Layout During Request

ROUTER PROCESS                   │  WORKER PROCESS (PHP)
                                 │
nxt_conn_t (conn_fd=42)         │  nxt_unit_ctx_t
 ├─ fd = 42                    │   ├─ port_fd  ← UDS socket to router
 ├─ read buf (4KB stack)        │   ├─ shm_fd   ← mmap shared with router
 ├─ write buf (8KB)             │   ├─ req_buf  ← incoming request
 └─ state = ACTIVE              │   └─ resp_buf ← outgoing response
                                 │
nxt_http_request_t (req_id=7)   │  PHP
 ├─ method = GET                 │   ├─ $_SERVER[] → request metadata
 ├─ target = "/index.php"        │   ├─ $_GET[]    → query params
 ├─ headers → linked list       │   ├─ $_POST[]   → body (if POST)
 ├─ app → drupal_app             │   ├─ $_COOKIE[] → cookies
 ├─ port_msg.pid → worker pid    │   └─ ob buffer  → response output
 └─ conn_fd = 42               │
                                 │
PORT (nxt_port_socket.c)        │  PORT (libunit)
 ├─ fd → UDS socket pair        │   └─ fd → same UDS socket pair
 ├─ type = APP_PORT             │
 └─ queue → pending messages    │
                                 │
SHARED MEMORY (mmap)             │  SAME SHARED MEMORY (mmap)
 ├─ fd = mem_fd                 │   └─ fd = mem_fd  (MAP_SHARED)
 ├─ offset chunk_id              │      └─ virt_addr → same physical pages
 └─ size = body_size             │

Key Data Structure Transitions

nxt_conn_t                    nxt_http_request_t
      │ (accept)                        │ (parse complete)
      ▼                                 ▼
nxt_h1proto_t              nxt_router_app_process_t
      │ (route match)                   │ (worker selected)
      ▼                                 ▼
nxt_app_t                   nxt_port_send_msg_t
      │ (IPC dispatch)                  │ (UDS write)
      ▼                                 ▼
waiting for worker            nxt_unit_ctx_t (worker side)
      │ (response ready)                │ (PHP handler)
      ▼                                 ▼
nxt_router_response_ready()   nxt_unit_response_t
      │ (headers + body)               │ (UDS write back)
      ▼                                 ▼
nxt_conn_write()              router receives response
      │ (writev to client)             │ (match request_id)
      ▼                                 ▼
client sees HTTP/1.1 200 OK   request_id freed, port queue slot freed

Concurrency: 100 simultaneous requests

LISTENER (epoll)
  │
  ├─ conn_fd=42 → req_id=7  → worker #3 (processing)
  ├─ conn_fd=43 → req_id=8  → worker #1 (processing)
  ├─ conn_fd=44 → req_id=9  → worker #5 (processing)
  ├─ conn_fd=45 → req_id=10 → waiting (all workers busy)
  ├─ conn_fd=46 → req_id=11 → waiting
  └─ conn_fd=47 → req_id=12 → waiting

Router:
  pending[req_id] → { events: tx, claimed_by: worker_id, body: rx }

Worker #3:
  req_id=7 → PHP handler running → 15ms left
  req_id=14 → waiting in port queue

Port queue (libunit):
  worker #1: [req_id=8]                 ← single request in flight
  worker #3: [req_id=7, req_id=14]      ← backlog
  worker #5: [req_id=9]                 ← single request in flight

Idle workers: worker #2, #4, #6, #7, #8 ← will pick req_id=10-12

Bottlenecks (what takes time)

Component             Time (typical Drupal)     Optimization
────────────────────────────────────────────────────────────
TCP accept              10 µs                   io_uring ACCEPT (Stage 2)
HTTP parse              90 µs                   pre-parse header cache
Route match              5 µs                   route table hash (already fast)
IPC send (small)        20 µs                   — negligible
IPC send (5MB upload)  200 µs + memcpy          body streaming (zero memcpy)
PHP boot (cold)       50 ms × N workers         Prototype + fork (once)
PHP boot (warm)         0 µs                    — P4 persistent worker
PHP handler          10–50 ms                   opcache + DB caching
DB query              0.5–5 ms                  connection pooling
IPC send response      20 µs                    — negligible
writev to client       30 µs + TCP TX            send_zc (zero-copy)

Takeaway: PHP handler dominates (98%), IPC is negligible (<0.1%), HTTP parse is <1%. Main wins: persistent workers (remove cold boot), opcache prototype+fork (share once), DB connection pooling (remove TCP per request).
