OpenCode Free tier — model tracking (SOUL ops reference)

_2026-09-03. Ground truth for the keyless OpenCode Free relay and the zen-quorum infrastructure. This is the canonical reference; the short fact lives in the zen-quorum skill and in MEMORY as a one-line pointer only._

Why keyless

The opencode-free provider profile is keyless by design: it sends an EMPTY Authorization header (_KEYLESS_HEADERS in opencode-free/__init__.py). The relay serves free-tier models anonymously and 401s any unrecognized bearer — so holding a key is pointless and sending a placeholder would break it. It also sends HTTP-Referer / X-Title / User-Agent attribution headers.

Profile accumulator (every-6h cron 6c821eeaa568)

tools/zen_models_profile.py runs every 6h (wrapper scripts/zen-models-profile.sh, script = filename only). It ACCUMULATES per-model knowledge into ~/.hermes/zen-models-state.json:

  • models.<id>.history — up to 200 samples (6h cadence) {ts, alive, dt, slow, err}
  • models.<id>.latency — rolling {n, min, max, avg, p95}
  • models.<id>.skills — specialization counters (tagged via --skill/--task)
  • models.<id>.last — most recent snapshot
  • model_specs.<id> — the static limit table above (re-read from source only rarely)

Probe is cost-bounded: max_tokens=4, 20s timeout per model, so even deep thinkers are gated. Output = only the delta (UP/DOWN/speed-flip); silent when nothing changed (watchdog pattern).

Commands:

python3 tools/zen_models_profile.py --report                 # readable summary
python3 tools/zen_models_profile.py --force                  # refresh now
python3 tools/zen_models_profile.py --skill <model> --task <type>   # tag specialization

Quorum runner

tools/zen_quorum.py — independent verdicts from several models on one issue/PR:

python3 tools/zen_quorum.py --repo freeunitorg/freeunit --pr 254
python3 tools/zen_quorum.py --text "<problem>" --choices "A|B|C|D"   # freeform pick
python3 tools/zen_quorum.py --pr 254 --save-kb
  • Accepts compact VERDICT: A :: WHY: ... and per-line formats; clamps verdict to

first token.

  • Parses verdict from content, reasoning_content, reasoning; retries 429/503/500.
  • max_tokens=4000 default (thinking preamble eats it; a low cap truncates BEFORE

the verdict and returns a prompt fragment).

  • Reports per-model verdict + divergence block; DIVERGENT = open question, don't

let one fast model outvote a slow careful one.

Practical (updated 2026-09-12): laguna is GONE from the live catalog — do not plan quorums around it. The free tier requires an x-session-id header (any UUID): without it the relay returns 400 MissingSessionID ("OpenCode's free tier can only be used in OpenCode") and it does so for EVERY model, so a script missing the header reports the whole tier down at once — read that as a header bug, not an outage. All three tools (zen_quorum.py, zen_tool_agent.py, zen_models_profile.py) now send one per process; the profiler was blind this way and showed ALIVE (0) until 2026-09-12 (guarded by a unit test). muse-spark 1.3/1.2-contributor-free are alive (~1s) but ONLY on the responses wire; chat/completions 500s there because the family never runs on that wire. deepseek-v4-flash-free is UNAVAILABLE upstream (400 server_error). mimo-v2.5-free answers on chat but 429s (FreeUsageLimitError) quickly on the shared quota. Nemotron/deep thinkers are slow and ignore format — exclude from frequent runs, keep only for deep one-off analysis at low cadence.

Quorum prompt context (fixed 2026-09-12): the runner used to cap the diff at 3 KB in the prompt and attach full source only for .c/.h, so a Rust or Python PR was reviewed with no code at all and every model voted PARTIAL "cannot verify, truncated". Caps are now DIFF_FETCH_CAP/DIFF_PROMPT_CAP (20/19 KB) with CODE_EXTS covering c/h/rs/py/go/js/ts/php/pl/rb. Extend CODE_EXTS when the tree gains a language. verify_spots()'s symbol index is still C-token oriented and labels real Rust symbols MADE-UP? — that label is a grader blindspot, verify by hand. Worked example: engineering/zen-quorum-wasm-stop-the-rest-of-the-request-path.md.
