Release 1.37.0 — check of the release description

Date: 2026-10-04. Ref: tag 1.37.0 = 61b297ac ("release: prepare 1.37.0", 04 Oct 2026); published on GitHub 2026-10-04T18:10:44Z. version = NXT_VERSION=1.37.0. Trigger: "проверь описание релиза".

Reproduced defect — the install commands in the release body 404

The GitHub release body (2087 chars, packaging text only) tells the reader:

DEB=1.37.0-1~trixie
curl -fLO "$BASE/freeunit_${DEB}_amd64.deb"

GitHub rewrites ~ to . in an uploaded asset name, so the stored name is freeunit_1.37.0-1.trixie_amd64.deb. Measured:

  • .../download/1.37.0/freeunit_1.37.0-1~trixie_amd64.deb → 404, and curl -f exits 22

(the copy-paste block fails at its second line);

  • .../download/1.37.0/freeunit_1.37.0-1.trixie_amd64.deb → 200, 5 366 112 bytes.

The body's own prose acknowledges the rename ("the . in the asset file name is GitHub's renaming of ~") while the commands keep the ~ form.

Worse, and older: SHA256SUMS (both 1.37.0 and 1.36.1) lists the files with ~ (11 lines), so sha256sum -c --ignore-missing SHA256SUMS matches nothing and silently verifies nothing. Newer than 1.37.0 — 1.36.1's manifest has the same naming.

CHANGES ↔ docs/changes.xml divergence (one entry)

Block ver="1.37.0" in docs/changes.xml: 115 entries (bugfix 60, change 31, security 16, feature 8). The CHANGES section: 116 (change 32). The extra entry is

Change: a QUIT that fails because the worker already exited is now logged at the info level, not as an alert.

Token-compare of all other entries found no other divergence (the njs 1.0.1 and the "upgrade contrib njs" wordings do match). Regeneration from the XML would drop that line from the site changelog.

Advisories

/repos/freeunitorg/freeunit/security-advisories lists two, both published 2026-07-17 (1.36.0 cycle). None for 1.37.0, whose 16 Security entries include request-reachable class fixes (shared compressor stream between clients, unescaped access-log JSON values, the route-regex ReDoS). Caveat: advisory drafts are not visible to the read-only token, so this is "publicly none", not "none exist".
