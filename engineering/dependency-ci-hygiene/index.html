Build & pinning

  • Build system: configure (193 lines) + auto/** shell; the Makefile is

GENERATED (no Makefile and no CMakeLists.txt in the tree). CMake appears only inside tooling (node-gyp in the clang-ast job).

  • Bundled contribs are pinned per component: `pkg/contrib/src/{wasmtime,njs,

wasi-sysroot,libunit-wasm}/version + SHA512SUMS`; source tarballs come from packages.freeunit.org checksum-verified. Bumps are ordinary PRs (njs 1.0.0 → 1.0.1, #387).

  • pkg/eol.json is the single source of truth: runtime/OS EOL with grace policy

(12 months runtimes / 36 months OS) PLUS a dependencies section documenting floor / floor_declared_by / tested_ceiling / source for openssl, tomcat, jetty, ecj, classgraph, wasmtime_c_api, wasmtime_crate. Read by pkg/eol and gated by eol-check.yml.

  • Compiler: -Wall -Wextra -Werror (auto/cc); make E=0 disables.

Style tooling

  • .editorconfig + .rustfmt.toml (Rust only). NO .clang-format,

.clang-tidy or cppcheck config anywhere in the tree, and no style target in the generated Makefile: C style is enforced by review, compiler warnings and clang-ast.

  • A whole-tree clang-format over ~133k lines of C would reformat against

several open PRs; only a changed-lines-only gate is cheap.

Linkage / module boundaries

  • C core (unitd) + loadable per-runtime language modules (.so) + libunit.a

linked into application processes (NXT_LIB_UNIT_STATIC, shipped by libunit-install). The Go binding includes only public nxt_unit*.h.

  • tools/unitctl is Rust in its own cargo workspace (unitctl,

unit-client-rs, unit-openapi), driving the control API over HTTP through the OpenAPI spec: zero link-time coupling to the C core, Cargo.lock committed, TLS behind a Cargo feature (#359).

Verdict on "adopt the sibling project's dependency hygiene" (2026-09-16 proposal)

  • Already done: per-component pinned + checksummed contribs, pkg/eol.json

as EOL/audit single source of truth, cargo audit over every lock, ASan+UBSan gate, libFuzzer PR gate, clang-ast AST gate, -Wall -Wextra -Werror, unitctl fully isolated from the C core.

  • Misapplied to this stack: pinning "in Makefile/CMakeLists" (build is

configure + auto/), "unitctl must not include deep internal headers / must link minimal shared libraries" (unitctl is Rust, no C linkage at all), valgrind/cppcheck/scan-build (already covered by the sanitizer gate + the clang-ast plugin), "avoid static linking of large components" (libunit.a is static by design for app processes).

  • Real deltas (2026-10-09): dependabot gomod and docker ecosystems (cargo

and github-actions are covered now); the 32-bit compile gate (#632) and the s390x hang (#624); a style-gate decision (changed-lines clang-format or a recorded "no"). Closed since the proposal: the unaudited contrib tarball (#400) and the Trivy decision (PR #99).
