🚀 FreeUnit 1.36.0

Вышла 16 июля 2026 года. 307 файлов, +19 034 / −5 581 строк относительно 1.35.5.

📡 OpenTelemetry — полностью переписан

  • Апгрейд OTel SDK: Rust-крейты с 0.24 на 0.32. Экспортёр переписан на выделенный поток с batch span processor — без tokio runtime, блокирующий reqwest клиент.
  • gRPC возвращается: settings/telemetry/protocol = http или grpc. OTLP/gRPC на tonic с небольшим tokio runtime, пока без TLS.
  • Traceparent: проброс upstream sampling decision через ParentBased(TraceIdRatioBased) — W3C trace flags больше не игнорируются.
  • mock OTLP коллектор: test/fake_otlp/ и test_otel.py — полный тестовый набор (span export, propagation, sampling, конфиг валидация).
  • Валидация конфига: batch_size (1–65536), sampling_ratio (0–1) теперь с внятными сообщениями об ошибках.
  • Логирование: eprintln из Rust-слоя заменён на C callback nxt_otel_log_cb — ошибки OTel текут в стандартный лог Unit.

🛠 Багфиксы

  • Go port-fd double-close: getUnixConn() дублировал fd через net.FileConn, а отложенный Close() закрывал оригинальный дескриптор — гонка с libunit, EBADF. Исправлено.
  • Cgroup.procs path bounds: snprintf возврат перезаписывал длину до проверки — переполнение при длинных путях. Теперь ENAMETOOLONG.
  • Cgroup directory leak: при OOM аллокации пула — созданная директория теперь удаляется, а не остаётся сиротой.
  • Proxy keepalive: после дублированного или некорректного Content-Length downstream keepalive остаётся выключенным — клиент не переиспользует соединение за пересобранным ответом.
  • Static NUL/empty paths: reject в templated share и chroot путях.
  • Controller conn tracking: целостный трекинг соединений и полная очистка на failure paths.
  • H1 buffer chain: завершение хвоста buf chain, оторванного trim-ом Content-Length.

📦 Пакетирование и инфраструктура

  • Debian rebrand: весь пакетный набор — freeunit, freeunit-dev, freeunit-php8.x, freeunit-python3.x, freeunit-perl, freeunit-go, freeunit-wasm, freeunit-jscNN. Демон: /usr/sbin/freeunitd, сокет: control.freeunit.sock.
  • njs: апгрейд contrib до 1.0.0.
  • CI: ASan+UBSan срез по lifecycle + runtime, seccomp и clang-ast gates.
  • Docker: обновлённые Dockerfile под 1.36.0.
