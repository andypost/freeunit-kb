Early community interest (pre-revival): 2023-06-09 — Pavel Zavadski (GitHub Pavlusha311245; Telegram @Pavlusha2Sniper) publishes a Habr tutorial about NGINX Unit ("Простым языком о простом NGINX UNIT", ~22K readers). He later becomes a FreeUnit contributor. The tutorial documents the pre-fork architecture (JSON config, REST API, /status, language modules, TLS via /certificates) — a useful "before" baseline for the "what FreeUnit added" narrative.

Timeline note (2026-08-31, verified): the Habr author Pavel Zavadski is the same person now contributing to FreeUnit — Telegram @Pavlusha2Sniper, GitHub Pavlusha311245. (Two handles, one person; not two accounts.)

What sets FreeUnit apart from upstream Unit

  • Active development (upstream archived)
  • Security hardening (14 audit vectors, 2 GHSA advisories)
  • OpenTelemetry 0.24→0.32 with gRPC
  • Graceful shutdown (SIGQUIT)
  • njs 1.0.0
  • wasmtime 36 (CVE fixes)
  • TrueAsync experimentation
  • Alternative-dispatch protocol research
  • Roadmap: P4 persistent workers, prototype+fork shared opcache, body streaming
